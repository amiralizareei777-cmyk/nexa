Quick start

Use Nexa to type, talk, open apps, find files, and create text or simple websites. You bring your own AI provider key, and Nexa stores it in Windows Credential Manager.

Set up Nexa in four steps

1Run Nexa.exe. Nexa opens the guide and settings on the first launch.
2Open the AI tab, choose a provider, and create an API key on its official site.
3Enter the key, click Refresh, select a model, and click Test Connection.
4Click Save. Open Nexa later with Alt+Space or its system tray icon.

An easy place to start

Google Gemini is often a simple way to create a key and try Nexa. Some models offer a limited free tier. Choose a model with audio input support for voice commands.

Voice and microphone

  • Listen starts a continuous voice conversation.
  • Say “Nexa” to show the edge glow, hear “Yes,” and start speaking.
  • Mute microphone stops wake-word listening, voice sessions, and microphone tests together.
  • Typed chat remains available while muted, and Nexa remembers the mute state after it closes.

Privacy and security

Nexa stores a separate key for each provider in Windows Credential Manager. Never share an API key in a message, screenshot, or public file.

Use the Privacy tab to disable AI access to screenshots or file names. Conversation context exists only during the current app session and can be cleared at any time. Nexa displays the exact shell command and asks for confirmation before running it.

Common errors

  • 401 Unauthorized: The key is incorrect, expired, or belongs to another provider. Enter a key from the selected provider.
  • 402 / insufficient credits: The API account has no usable credit. A ChatGPT subscription does not fund OpenAI API usage.
  • 429: The request or free-tier limit has been reached. Wait and retry, or check the provider's billing page.
  • Voice is not recognized: Choose the correct language in Voice, run Test Microphone, and verify that the model or STT route accepts audio.
  • OmniRoute is unavailable: The dashboard at localhost:20128 must open and the OmniRoute service must be running.
