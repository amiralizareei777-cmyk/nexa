NEXA 1.0 — QUICK START
======================

1) Run Nexa.exe.
2) On the first launch, open Quick start and then the AI tab.
3) Choose a provider and enter an API key from that same provider.
4) Click Refresh, Test Connection, and finally Save.
5) Open Nexa at any time with Alt+Space or the system tray icon.

An easy provider to try first: Google Gemini
Create a key: https://aistudio.google.com/app/apikey

Important:
- A ChatGPT subscription does not include OpenAI API credits.
- OmniRoute works only while it is running on the same computer and connected to an upstream provider.
- Mute microphone stops all listening; typed chat remains available.
- Never share your API key in a message, screenshot, or public file.
- To quit completely, choose Exit from Nexa's system tray menu.

Full guide: Nexa-Guide.html
