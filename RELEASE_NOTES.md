# Nexa 1.0.0

The first release-ready version of Nexa for Windows 10 and 11.

## Highlights

- Resizable main window with minimize, taskbar presence, and F11 full screen
- Instant access through Alt+Space and the system tray
- Typed chat, voice conversations, and the “Nexa” wake word
- One global microphone mute control for wake-word listening, voice sessions, and microphone tests
- OpenAI, Gemini, Claude, OpenRouter, OmniRoute, and custom OpenAI-compatible providers
- Separate API keys for each provider, stored in Windows Credential Manager
- Built-in English setup guide with official provider key links
- App, file, folder, and URL launching; file search; screenshots; system information; and volume control
- Direct creation of text, code, and HTML files, with support for opening the created file
- Mandatory confirmation before running a shell command
- Privacy controls, in-session conversation memory, and light and dark themes
